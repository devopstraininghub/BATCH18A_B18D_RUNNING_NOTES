## 1. Five modules worth knowing

| Module | Type | What it's for |
|---|---|---|
| `os` | Standard library | OS interaction — files/directories, env vars, running system commands |
| `sys` | Standard library | Python runtime/interpreter access — command-line args, exiting, the module search path |
| `shutil` | Standard library | High-level file operations — copying/moving/deleting files and whole directories |
| `boto3` | External (AWS SDK) | Automating and managing AWS services |
| `psutil` | External | System monitoring — CPU, memory, disk, running processes |

**`os` — common operations:**
```python
os.system("ls")            # run a shell command
os.getenv("USERNAME")      # read an environment variable
os.makedirs("new_folder")  # create a directory (including parents)
```

**`sys` — common operations:**
```python
sys.argv   # the list of command-line arguments
sys.exit() # exit the script, optionally with an exit code
sys.path   # the list of directories Python searches for modules
```

**`shutil` — common operations:**
```python
shutil.copy("a.txt", "b.txt")     # copy one file
shutil.copytree("src", "dest")    # copy an entire directory tree
shutil.disk_usage("/")            # (total, used, free) bytes on that disk
```

**`boto3` — common operations:**
```python
boto3.client("s3")      # low-level AWS service client
boto3.resource("ec2")   # higher-level, object-oriented AWS interface
```
- Real use cases:
  - Start/stop EC2 instances.
  - Upload/download S3 objects.
  - Manage IAM, Lambda, RDS, and more.
- This is the library behind almost every Python-based AWS automation script.

**`psutil` — common operations:**
```python
psutil.cpu_percent()        # current CPU usage, as a percentage
psutil.virtual_memory()     # RAM usage details
psutil.disk_usage("/")      # disk usage details (similar shape to shutil's)
```

## 2. Real-time use case — check if a server is reachable

**Using a command-line argument for the server address:**
```python
import os
import sys

def ping_server(server_ip):
    response = os.system(f"ping -n 1 {server_ip}")
    if response == 0:
        return True
    else:
        return False


if __name__ == "__main__":

    # server_ip = input("Enter the server IP or hostname to ping: ")

    server_ip = sys.argv[1]

    if ping_server(server_ip):
        print(f"Server {server_ip} is reachable.")
    else:
        print(f"Server {server_ip} is not reachable.")
```
**Running** `python3 ping_check.py google.com` **on Windows:**
```
Pinging google.com [<IP address>] with 32 bytes of data:
Reply from <IP address>: bytes=32 time=<X>ms TTL=<Y>
...
Server google.com is reachable.
```
- `os.system(...)` doesn't capture the ping command's output — it just runs it, so the real `ping` output prints to the terminal first, **then** the script's own message. The exact IP/timing/TTL numbers depend entirely on the network, so treat the ping output above as illustrative, not exact.
- `os.system()` returns `0` when the underlying command succeeds — that's what `response == 0` is checking.
- ⚠️ `ping -n 1` is the **Windows** syntax (`-n` = number of pings). The Linux/macOS equivalent is `ping -c 1` (`-c` = count) — running `-n` on Linux would fail, since `ping` there doesn't recognize that flag the same way.

**A shorter variant — same idea, no `-n 1` (so Windows' default of 4 pings runs instead of just 1):**
```python
import os
import sys

def ping_server(server):
    response = os.system(f"ping  {server}")
    return response == 0

server = sys.argv[1]

if ping_server(server):
    print(f"Server {server} is up")
else:
    print(f"Server {server} is down")
```

**A third variant — reading the server interactively instead of from the command line:**
```python
import os

def ping_server(server):
    response = os.system(f"ping {server}")
    return response == 0

server = input("Enter server name or IP: ")

if ping_server(server):
    print(f"Server {server} is up")
else:
    print(f"Server {server} is down")
```
- All three do the same core thing — the differences are just **where the server address comes from**: a command-line argument (`sys.argv[1]`), the same but without limiting to one ping, or `input()` for an interactive run.

## 3. Real-time use case — back up a directory

```python
import shutil
import os

# Directory to backup
source_dir = r"C:\Users\Dell\Desktop\k8s"

# Backup destination
backup_dir = r"C:\Users\Dell\Desktop\k8s_backupfiles"

# Ensure backup directory exists
os.makedirs(backup_dir, exist_ok=True)

# Copy the directory
shutil.copytree(source_dir, os.path.join(backup_dir, os.path.basename(source_dir)))

print("Backup completed successfully")
```
- `os.path.basename(source_dir)` pulls just `"k8s"` out of the full path — so the copy lands at `k8s_backupfiles\k8s`, nested one level inside the backup folder, not dumped directly into it.
- `os.makedirs(backup_dir, exist_ok=True)` creates the backup folder (and any missing parent folders) — `exist_ok=True` means it won't raise an error if the folder is already there.

**An interactive variant — paths typed in at runtime instead of hardcoded:**
```python
import shutil
import os

source_dir = input("Enter source directory path: ")
backup_dir = input("Enter backup directory path: ")

os.makedirs(backup_dir, exist_ok=True)

shutil.copytree(
    source_dir,
    os.path.join(backup_dir, os.path.basename(source_dir))
)

print("Backup completed successfully")
```

**A function-based variant, with exception handling:**
```python
import os
import shutil

def backup_directory(source_dir, backup_dir):
    try:
        shutil.copytree(source_dir, backup_dir)
        print(f"Backup of '{source_dir}' created at '{backup_dir}'")
    except Exception as e:
        print(f"Error during backup: {e}")


if __name__ == "__main__":
    source_directory = r"C:\Users\Madhukiran\Desktop\k8s"
    backup_directory_path = r"C:\Users\Madhukiran\Desktop\k8s_backupfiles"
    backup_directory(source_directory, backup_directory_path)
```
- ⚠️ This variant calls `shutil.copytree(source_dir, backup_dir)` **directly** — no `os.path.basename()` nesting like the first variant. That matters: `copytree`'s destination folder must **not already exist** (it creates it), so running this script a second time against the same `backup_dir` raises `FileExistsError` — which this version's `try`/`except` catches and reports cleanly instead of crashing.

## 4. Real-time use case — monitor disk usage

```python
import shutil

monitor_dir = r"C:"

# Disk usage threshold (in percentage)
threshold = 80

# Get disk usage
total, used, free = shutil.disk_usage(monitor_dir)  # returns a tuple of three values

print(total, used, free)  # total, used, and free bytes on the disk

usage_percent = used / total * 100

if usage_percent > threshold:
    print(f"Warning: Disk usage is {usage_percent:.2f}%")
else:
    print(f"Disk usage is {usage_percent:.2f}%, within the threshold")
```
**Sample output** (exact numbers depend entirely on the machine's actual disk — this is illustrative, not a fixed result):
```
512110190592 322485370880 189624819712
Disk usage is 63.00%, within the threshold
```
- `shutil.disk_usage(path)` returns a tuple `(total, used, free)`, all in **bytes** — dividing `used / total * 100` gives the percentage used.
- `f"{usage_percent:.2f}"` formats the float to exactly 2 decimal places.

**A function-based variant:**
```python
import shutil

def get_disk_usage(path):
    total, used, free = shutil.disk_usage(path)
    return total, used, free


if __name__ == "__main__":
    path = "/"
    total, used, free = get_disk_usage(path)
    print(f"Total: {total}, Used: {used}, Free: {free}")

    usage_percent = (used / total) * 100
    print(f"Disk usage percentage: {usage_percent:.2f}%")

    if usage_percent > 80:
        print("Warning: Disk usage is above 80%!")
    else:
        print("Disk usage is within acceptable limits.")
```
- Same idea, wrapped in a reusable function — `path = "/"` is the Linux/macOS root filesystem; on Windows this would be `"C:"` like the first variant.

| Concept | One-line meaning | Real-time (DevOps) example |
|---|---|---|
| `os` | OS interaction — files, env vars, shell commands | `os.system()`, `os.getenv()`, `os.makedirs()` |
| `sys` | Interpreter/runtime access | `sys.argv`, `sys.exit()` |
| `shutil` | High-level file/directory operations | `shutil.copytree()`, `shutil.disk_usage()` |
